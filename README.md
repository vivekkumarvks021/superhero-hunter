# Superhero Hunter JS

A vanilla JavaScript web application to search superheroes, view their details, and manage a list of favourite superheroes using **localStorage**.

## Features

### 1. Home Page

- Search superheroes by name using the **Superhero API**
- Display matching superhero cards
- Add superheroes to the **Favourites** list
- Click on a superhero card to open the **details page**

### 2. Superhero Details Page

- View detailed information about a superhero
- Displays important details such as:
  - Name
  - Full Name
  - Publisher
  - Alignment
  - Powerstats
  - Appearance
  - Work and Connections

### 3. My Favourite Superheroes Page

- Displays all favourited superheroes
- Favourites are stored in **localStorage**
- Data persists even after page refresh or browser restart
- Remove superheroes from favourites
- Click on a favourite superhero card to view its details page
